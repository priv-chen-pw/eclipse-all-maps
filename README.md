# Eclipse All Maps

> **Made only for more randomized Eclipse runs.** Early version: please report bugs and balance issues on [GitHub](https://github.com/priv-chen-pw/eclipse-all-maps).

## TL;DR

* Reformed Altar, Treeborn Colony, Conduit Canyon and Void Locus join the stage rotation.
* Portals that lead off the rotation are closed.
* After stage 5 comes a random final boss. Beat it, then end the run at a new altar or loop.
* Only the host needs the mod.

### The altar

<!-- Altar GIF goes here, e.g. ![The altar](https://raw.githubusercontent.com/priv-chen-pw/eclipse-all-maps/main/docs/images/altar.gif) -->

A stone altar with the Eclipse emblem, under a victory beam, beside the arena's exit. It only appears on your final stage. Use it to win the run with that boss's ending. Players without the mod see a Shrine of Order.

### Other changes

* No green portals and no portals to Solutional Haunt. Access codes still give their extra boss and item.
* Halcyon Shrines can spawn on every stage, weaker from stage 4.
* From stage 4 the Alloy Hunter can be a teleporter boss: one, plus one per Shrine of the Mountain.

### Settings

In **Settings → Mod Options** (Risk Of Options) or r2modman's config editor: switch the mod off, change how often the new maps roll, or turn off any new map, final boss, the extra Halcyon Shrines or the Alloy Hunter. Changes apply from the next stage. DLC content you don't have is skipped.
